## What This Is
Production-grade LLM evaluation framework built during 
transition into AI Quality Engineering. Integrates 
DeepEval, MLflow, Evidently AI, and Ragas into a 
unified AI quality gate with full audit trail.

## Projects

### 1. Medical Chatbot Evaluator (DeepEval + MLflow)
- pytest fixture architecture for reusable metric logging
- Logs every evaluation run automatically to MLflow
- Handles timeouts gracefully — TIMEOUT_CRITICAL signal
- Creates verifiable audit trail for AI model deployments
- Tools: DeepEval, MLflow, Ollama (Mistral), pytest

### 2. E-Commerce Chatbot Evaluator
- Tests faithfulness, hallucination, answer relevancy
- Order status, return policy, customer care scenarios
- Tools: DeepEval, Ollama (Mistral), pytest

### 3. ML Drift Detection Monitor
- Detects statistical distribution shifts in production data
- Generates automated HTML drift reports
- Tools: Evidently AI, Pandas, NumPy
